# 🏥 Medical Chatbot

An AI-powered Medical Chatbot designed to provide users with instant responses to general health-related queries. The chatbot leverages Natural Language Processing (NLP) and Machine Learning techniques to understand user symptoms, answer healthcare questions, and provide basic medical guidance. It is intended for informational purposes only and does not replace professional medical advice.

---

## 🚀 Overview

The Medical Chatbot acts as a virtual healthcare assistant, enabling users to interact through a conversational interface. It can answer common medical questions, provide information about symptoms and diseases, and assist users in understanding basic healthcare concepts.

> **Disclaimer:** This chatbot is intended for educational and informational purposes only. It is **not** a substitute for professional medical diagnosis, treatment, or advice.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/SomilSingh128/Medical-chatbot.git
```

### 2. Navigate to the project

```bash
cd Medical-chatbot
```

### 3. Create a virtual environment (Optional)

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open your browser

```
http://127.0.0.1:5000
```

## 🔄 Workflow

1. User enters a medical question or symptom.
2. The chatbot processes the input using NLP techniques.
3. The system identifies keywords and user intent.
4. The model retrieves the most relevant medical information.
5. The chatbot generates a response.
6. The response is displayed to the user in real time.
